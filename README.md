# 麻将研习 · 连续舍牌（8.0.0）

安静地练习打哪张。每组五副起手，每副最多三次舍牌；先回应，再沿着自己的真实选择继续。

## 运行

Node 24.19.0，pnpm 9.15。安装后运行 pnpm dev；pnpm build 构建独立页面，pnpm build:package 导出 @neo/mahjong-learning。宿主引用 GitHub Release 完整提交版本，嵌入时共用宿主路由。

## 保留与收敛

- 练牌、我的进步、更多。白玉牌图和轻微过渡，纯音乐由玩家主动开启；不会下载故事场景或整套声音后才允许练习。
- 仅条、筒。先最小化向听，同距离再比较有效余量；所有精确并列都接受。它不是完整实战 EV 或胜率预测。
- 看清牌形、比较取舍、加入约束三档。复用经校验的舍牌题；旧多步收益、攻防模型不混作效率判分。
- 确认舍牌后冻结当前手牌与解释，点击继续才揭开下一张。保留全部未打出的实体与顺序；三次后明确换起手，计算窗口结束不称流局。
- IndexedDB 自动保存选择、提示、有效用时、当前副与反馈阶段。旧故事和旧报告保留，不追溯计入新训练正确率。
- 首次独立起手按母牌形去重；换种子不增加样本。后续、辅助、复练单列。少于五副只描述一手；五副以上且三次同类问题才描述初步倾向。
- 我的进步提供事实、原手牌和定向五副；AI 只选择经过服务端重判的观察与练习方向。上传前确认，快照9、报告7，55秒服务截止、70秒浏览器等待、私有保存90天。

## 验证

pnpm test:coverage、pnpm test:oracle、pnpm bank:verify、pnpm story:verify、pnpm journey:verify 保留历史引擎与兼容门禁。

pnpm test:practice-browser 检查 Chromium/WebKit 的五副连续流程、刷新、重复实体、提示续存、六档宽度与深浅主题，以及默认无音乐和故事图片请求。

详细条件与发布记录见 docs/practice.md。旧叙事入口保留为 /legacy-journey-app 与 /legacy-story-app，供固定版本回滚；正常入口直接练牌。
