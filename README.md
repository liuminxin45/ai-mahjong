# 麻将研习

成都麻将缺门后的舍牌学习工具。每道练习只做一件事：从手牌中选出一张要打掉的牌。正式入口：[麻将研习](https://www.liuminxin.cn/works/mahjong)。

## 学习体验

- **练习**：保留简洁首页，每组5题。先比较离听牌的距离，再比较能前进一步的剩余张数，所有并列最优均接受。提示与重复作答不增加独立样本。
- **学习路线**：4阶段、8短课，包含例题、分步观察、常见错误与练习入口。可以自由选课，阅读不等于掌握。
- **我的进步**：分课显示客观表现，错题按浏览器本地日期间隔1、3、7天复习。可主动上传全部相关作答，生成简短AI学习小结。
- **摆一手自己的牌**：次要工具，点图选牌，先看推荐舍牌；向听、进张、碰杠、已见牌与文字牌谱放在详情中。

新题库 `discard-3` 含96种非等价牌形：8道讲解例题、88道独立练习。每课有11道练习；例题不进入测量样本。默认组安排3道当前新题、1道适合当前阶段的到期错题、1道迁移题；没有错题时补新题。最近10种首次独立牌形至少8道正确后引入下一课。这是练习编排参数，不是能力等级认证。

## 规则与依据

仅一至九筒、一至九条，每种4张，共72张。普通和型是四组面子加一对将；七对允许四张同牌算两对，有固定组合时不走七对。公开组合只用碰、杠；手牌内部仍可组成顺子。余量表示尚未见到的张数，不是实际牌墙摸牌概率。

规则参考 [MIL 四川麻将规则纲要](https://mahjong-mil.org/wp-content/uploads/2024/08/Brief_Introduction_to_Bloody_Mahjong-1.pdf) 第2节碰杠与不能吃、第3节基本和型与缺门，以及七对说明。双花色是本工具的专项范围，不覆盖完整成都麻将的108张对局与计分。

教学组织参考 [IES 学习指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/1) 的例题和独立练习交替、提取练习及间隔复习原则。题库难度尚无真人标定。

## 开发与验证

Node 24.19.0、pnpm 9.15.0：

```sh
pnpm install
pnpm dev
pnpm test:coverage
pnpm bank:verify
pnpm test:oracle
pnpm build
pnpm build:package
pnpm check:ui
```

预览启动后运行 `pnpm test:training-browser`、`node scripts/training-storage-browser.mjs` 和 `node scripts/analysis-browser.mjs`。可用 `MAHJONG_PREVIEW_URL` 设置预览地址，`MAHJONG_ROUTE_BASE` 设置宿主路径。具体用例见 [测试用例](docs/discard-test-cases.md)。浏览器模拟与真机验证分别记录，未把模拟结果当作真机结果。

共享UI固定为0.8.6、提交 `1845915f76e6cc5834f053d5666517650960aa89`，使用DesktopProvider和局部样式。imagegen牌图、原始PNG、提示词与多尺寸WebP继续复用。

## 记录与兼容

沿用IndexedDB `neo-mahjong-learning-v1`。旧作答、草稿、课程与报告原样留存，新学习状态放在独立 `training` 字段。只有目标一致、非比赛、无多步目标且新旧答案一致的旧何切可以纳入进度；其他记录仅归档。新引擎1.0.2修正了暗手四张同牌可能产生的虚假第五张等待，旧1.0.1引擎冻结用于历史重建。

JSON备份包含新旧数据，导入会校验并重判，不相信导入的正确率。存储失败时仍可练习和导出。`/manual` 与旧课程链接映射到新路线，`/review`、`/profile`进入我的进步，旧比赛与测验链接回练习首页。

排位赛不再开放新开赛（HTTP410）；已签发答卷可在原24小时有效期内通过旧客户端完成，不延长有效期。不删除比赛私有表及历史成绩。

## AI与宿主集成

源码、引擎、课程和资源在本仓库维护；个人网站通过GitHub Release包的完整提交SHA引用，构建核验 `build-info` 与锁文件，不维护第二份业务源码。独立运行使用自己的路由，宿主嵌入使用宿主路由。

新快照v4只包含相关舍牌作答，服务端重建题目并重新判分。全部历史先汇总为分课事实和代表题，再交给本站既有模型。能力事实与下一课由程序决定；模型只解释一个具体学习动作，不判题、不推断思考原因、不提供实战评级或一周日历。少于5个独立样本不形成该课统计结论。

生成小结需用户主动确认上传；默认练习仍仅存本地。沿用签名访客Cookie、私有报告存档、同快照成功缓存、90天保留、55秒模型截止和70秒客户端等待。保留旧报告读取与删除。接口路径继续为 `/api/assistant/mahjong/profile`（POST）及 `/profile/:id`（GET、DELETE）。
