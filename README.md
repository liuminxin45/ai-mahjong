# 麻将研习 · ai-mahjong

成都麻将缺门后的双花色专项训练工具，保留何切、有效进张、听牌与多面听、七对和攻防五类训练。规则参考[MIL四川麻将纲要](https://mahjong-mil.org/wp-content/uploads/2024/08/Brief_Introduction_to_Bloody_Mahjong-1.pdf)，双花色72张与四张算两对作为工具约定单列，不模拟完整108张实战。

正式入口：[麻将研习](https://www.liuminxin.cn/works/mahjong)。独立仓库维护引擎、题库、课程、React界面和imagegen麻将资源；个人网站通过完整提交SHA引用本包，并提供匿名画像服务。

## 规则与边界

- 一至九筒、一至九条，每种四张，共72张。
- 普通型为四组面子加一对将；七对允许四张同牌算两对，且无固定组合。
- 成都规则禁止吃牌，新题与编辑器公开组合只有碰、杠，内部顺子仍可成牌；旧版固定顺子可读。物理张数与结构张数分别校验。
- 不提供完整对局、地区计分、立直役种或自博弈。攻防题给出明确的教学假设与评分目标，不推断真实放铳概率。

## 本地运行

使用Node 24.19.0、pnpm 9.15.0：

```sh
pnpm install
pnpm dev
pnpm test:run
pnpm test:coverage
pnpm bank:verify
pnpm test:oracle
pnpm build
pnpm build:package
pnpm check:ui
```

默认地址为http://127.0.0.1:5173。Git依赖需要正常执行prepare，不使用ignore-scripts。Windows的pnpm虚拟目录已限制长度，避免Git依赖中的井号影响Vite资源URL。

## 功能

首页提供学习路线、课程与已有练习继续入口；侧栏包含排行榜和GitHub链接。保留13/14张与固定组合分析、错题收藏和本地日历1/3/7天复习。24节课程新增先修、分步例题、来源和掌握标准，参考[IES学习指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)安排例题、提取练习和间隔复习。“已读”不等于掌握。

题库2.0.0提供600道分级练习与120道独立比赛题，五专项×六档每格20练习、4比赛。花色互换、数字镜像和排列等价不增加独立样本。六档为入门、基础、进阶、困难、大师、地狱；同档20题中至少17题正确推荐升级，少于10题推荐降级，可手动选择，地狱级主动进入。192道多步题采用明确的均匀不放回抽牌袋，离线精确求解、独立路径实现复核，页面展示整数路径与关键后续分支。地狱题有4—6摸窗口、状态数门槛和接近方案筛选；仍属于设计难度，尚无真人标定。旧80道种子题及旧生成器保留为历史重建器。

练习默认存IndexedDB，可导入导出。主动生成画像时上传全部历史，快照v3兼容v1/v2；服务端重建并重判，压缩全历史统计与代表题。按知识点×难度展示样本、正确率和95% Wilson区间；少于5题证据不足，5—19题初步观察。速度只比较同类同档独立正确练习，比赛耗时另计。新版能力结论由程序生成，LLM只安排允许的课程与动作，不推断性格、思考原因或实战胜率。沿用本站模型、签名访客身份、55秒模型截止、70秒浏览器等待和90天报告保留。输入上限50000条／8MB，超限拒绝而不截断。

## 匿名挑战榜

`/leaderboard`替代阶段测验，`/quiz`跳转；旧草稿可在`/quiz/legacy`继续本地测验，不追溯上榜。每档固定20题，五类各4题，每题5分，多选与信息判断须完全正确，可反复挑战并保留最好成绩。

服务端连续计时，后台、断网与刷新均计入；24小时内恢复同答卷，每位访客最多一场进行中，可放弃重开。逐题提交后锁定，第20题原子判分与更新。排序按得分降序、毫秒耗时升序、达到时间升序；新卷新榜。旧榜停止新开赛，已有答卷可在原24小时内完成，之后只读。

无账号，沿用签名Cookie并显示匿名代号。清理Cookie或更换浏览器会成为新访客；固定卷允许熟悉题目，无法保证真人唯一或排除外部计算。比赛会上传作答，普通练习继续仅本地保存。在线服务不可用仍可练习。

## 包接口

- 主入口：MahjongApp、createProfileClient与createCompetitionClient，可注入画像和比赛客户端。
- /engine：无DOM依赖的规则校验、向听、听口、进张和拆解。
- /learning：课程、可复建题库、判分、快照及画像校验。
- /worker：可由宿主Vite以?worker加载的分析线程。
- /styles.css：局部业务布局。

MahjongApp使用宿主路由，接收basePath、assetsBaseUrl、主题、Worker工厂与画像客户端。宿主使用/works/mahjong/*，通过懒加载隔离学习工具。基础UI固定使用chatgpt-desktop-kit 0.8.6，提交1845915f76e6cc5834f053d5666517650960aa89。

## 资源与验证

assets/tiles/source保留20张imagegen原始PNG，prompts.json保存提示词；manifest.json绑定SHA与96/192/384px WebP。node scripts/tiles.mjs重新压缩，node scripts/stage-assets.mjs为独立预览分发资源。牌图图案由imagegen生成，压缩脚本不重画符号。

完整案例见[测试用例](docs/test-cases.md)。核心算法、判题和统计分支门槛95%；独立目标枚举与证书同时验证。`pnpm test:oracle`默认10000份双花色样本，日常覆盖率使用240份。`pnpm bank:verify`重查720题与192份多步证书；发布后不可在相同版本下更换题目和答案。

`pnpm test:upgrade-browser`检查Chromium/WebKit、六种宽度和深浅主题，比赛传输使用模拟，真实SQL事务由宿主测试。截图和结果保存在忽略的artifacts/。浏览器模拟不等同于真机或真人难度标定。

旧版成都麻将代码保留在Git历史，旧对局、回放与参数不迁入新存储。已知旧学习版本保留重建器，未知版本明确拒绝，不把新规则静默套到旧证据上。

## 网站安装产物

正式网站安装GitHub Release上的预构建包，发布标签包含完整源码提交号。包内的build-info.json记录相同提交，网站分发资源前会核对依赖URL与该提交是否一致；锁文件校验包完整性。运行包只含编译模块、WebP与资源清单，原始PNG继续保存在本仓库。共享UI仍使用固定Git提交并正常执行prepare，应用源码只有这一份。
