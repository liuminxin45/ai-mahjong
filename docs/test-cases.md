# 麻将研习2.0测试用例

本表规定条件和预期；执行结果记录于CI、覆盖率和浏览器产物。真机与真人难度标定需要真实设备和参与者，不由模拟替代。

## 执行入口

| 检查 | 命令 | 通过条件 |
| --- | --- | --- |
| 类型、独立应用、发布包 | `pnpm build`、`pnpm build:package`、`pnpm check:ui` | 导出、图片分发与组件库集成通过 |
| 单元与覆盖率 | `pnpm test:coverage` | 全部用例通过；核心分支／语句／行／函数≥95% |
| 题库证书 | `pnpm bank:verify` | 720题身份、覆盖、物理约束、基础答案和192份独立多步证书正确 |
| 扩大随机对照 | `pnpm test:oracle` | 默认10000份双花色样本无差异 |
| 新交互 | `pnpm test:upgrade-browser` | 两引擎×六宽度×深浅主题，比赛传输模拟 |
| 原交互 | `pnpm test:browser`、`pnpm test:editor`及selection/profile/home脚本 | 选牌、旧草稿、主题、焦点和导航回归通过 |
| 宿主服务 | 宿主`npm run test:mahjong` | PGlite真实SQL、访客归属、模型边界全部通过 |

先启动预览并设置`MAHJONG_PREVIEW_URL`；宿主另设置`MAHJONG_ROUTE_BASE=/works/mahjong`。升级浏览器脚本默认5188端口，其他脚本保留原默认值。

## 引擎与精确模型

| ID | 条件／操作 | 预期 |
| --- | --- | --- |
| E01 | 普通四面子一将、七对、四张贡献两对 | 成牌正确，七对仅在无固定组合时使用 |
| E02 | 固定碰／杠 | 杠实际四张、结构一面子，分别扣除与校验 |
| E03 | 固定刻子外尝试同牌等待 | 不制造第五张或假听牌 |
| E04 | 合法听口全部见尽 | 形状听口保留、余量为0，不计直接进张 |
| E05 | 比较舍牌后的进张 | 刚舍出的牌仍为已知，不回到余量中 |
| E06 | 非法花色、第五张、错误牌数、组合或规则 | 明确拒绝输入 |
| E07 | 多个等向听等进张选项 | 全部接受，无人为唯一答案 |
| E08 | 双花色随机牌、不同固定碰杠容量 | 与独立完整和型目标枚举器一致，种子可复现 |
| D01 | 袋中不同实体副本、不放回 | 物理权重、公共整数分母和精确并列正确 |
| D02 | 中途提前成牌 | 停止摸打，正确计入后续吸收路径 |
| D03 | 每次摸牌后重新舍牌 | 决策只使用当时信息，不预知未来顺序 |
| D04 | 七对、普通型、条件首摸、安全候选 | 按明确目标评分 |
| D05 | 袋内第五张、非法步数、牌数不符、无候选、节点预算耗尽 | 拒绝求解与发布，不用近似值冒充精确答案 |
| D06 | 已发布4／5／6摸题 | 独立实体牌路径实现与生产证书一致 |

## 画像与匿名比赛

| ID | 条件／操作 | 预期 |
| --- | --- | --- |
| P01 | 0／1／12／超过100次作答 | 0不可提交；有记录可生成，全历史参与，无20题门槛 |
| P02 | 简单题全对、难题全错 | 知识点与难度分层，避免混合正确率掩盖问题 |
| P03 | n<5、5≤n<20、全对／全错 | 证据不足／初步观察与Wilson区间正确 |
| P04 | 错题快、提示快、比赛快、异常用时 | 不作为普通独立正确练习速度证据 |
| P05 | 同知识点同档前后各10题 | 区间重叠时不宣称稳定改善 |
| P06 | 模型虚构判断、证据或课程 | 拒绝；新版能力事实由程序生成，AI只安排允许课程 |
| P07 | 重复报告、55秒截止、越权读删 | 成功复用、超时可主动重试、越权拒绝，本地数据保留 |
| P08 | 大于40KB历史／超过8MB | 云入口允许前者；超限明确拒绝，不截断 |
| R01 | 新访客、清理Cookie、伪造身份 | 签名Cookie决定归属，榜单不公开访客UUID |
| R02 | 重复开赛、同访客另一试卷、多标签 | 幂等恢复同答卷，最多一场进行中 |
| R03 | 自报分数、耗时、跨题、改已答题 | 不信任自报指标；越序、非法答案与改写被拒绝 |
| R04 | 后台、刷新、断网、24小时到期 | 连续计时、恢复原进度，到期不参榜 |
| R05 | 最后一题、重复交卷、并发提交 | 只结束与计分一次，最好成绩原子更新 |
| R06 | 高分慢、低分快、同分快、完全相同 | 分数优先、毫秒用时次之、达到时间再次之 |
| R07 | 新试卷版本／同版本内容被改 | 新版本新榜，旧榜停止新开赛；原有答卷可在原24小时内完成，之后只读；同版本冲突拒绝注册 |
| R08 | 历史答卷和核验记录 | 非最好历史按保留策略清理，最好成绩与依据保留；报告独立90天 |
| R09 | 在线服务关闭、网络错误、Cookie不保留 | 可恢复错误，本地练习仍可用，不伪造线上成绩 |
| R10 | 刷新、回到页面、重新联网，已选重复牌 | 自动续接；同一题保留选中副本，进入下一题才清空选择 |
| R11 | 提交成功但响应丢失、旧恢复请求晚到 | 自动读回已保存答案；旧响应不覆盖新题或新比赛 |
| R12 | 重新挑战取消、放弃后开赛响应丢失 | 取消保留选择；确认后沿用同一个开赛编号重试，不重复开赛 |

## 视觉和发布

- Chromium／WebKit，1920、1280、768、390、360、320px，深浅主题、键盘与触屏。
- 可操作牌面至少44px；页面不横向溢出，工作区一个纵向滚动区，表格可在局部容器查看。
- 验证弹窗焦点、主题切换状态、手册来源、旧测验继续、非法链接返回、首页懒加载。
- 独立包、宿主固定提交、UI组件库和build-info匹配；数据库先兼容，再发布函数与前端。
- 正式域名验证匿名比赛、真实模型报告读取删除，并清理本次生成的测试数据。
- 真机与真人标定：待真实设备／参与者执行，不记为模拟通过。

界面与续接专项检查：`node scripts/product-browser.mjs`。包括GitHub图标唯一入口、排位赛命名、手机成绩列表、无技术性常驻提示及上述R10—R12恢复路径。

## 2.0.2规则与示例

命令：`pnpm test:coverage`、`node scripts/guides-browser.mjs`。后者检查Chromium/WebKit、六档屏宽和深浅主题；比赛接口采用模拟，不产生线上成绩。

| 编号 | 条件与操作 | 预期 |
| --- | --- | --- |
| G01 | 首次依次进入五类练习，关闭说明，再刷新或切难度 | 每类首次自动显示，已读后不重复弹出，手动入口一直可用 |
| G02 | 打开有效进张示例，将已见四条从0改为3、4张 | 总余量由8变5、4张；四条见尽后只选七条；听牌示例仍包含两种形状听口 |
| G03 | 检查何切、七对示例牌与计算结果 | 每种牌不超过4张，九条是唯一最优；四张一筒算两对，六条／七条均为七对最优 |
| G04 | 已选答案后重开说明，打开示例Select，连续按Escape | 先关闭Select，再关闭说明；原选择保留，焦点回到规则按钮 |
| G05 | 阅读说明20秒、答题2秒、重看15秒、再答题1秒 | 普通练习有效用时约3秒，说明不算提示，记录不标记为辅助作答 |
| G06 | 进入排位赛的开始弹窗，逐类查看例子，取消或确认 | 确认前不发开赛请求；取消返回原按钮；确认只开赛一次 |
| G07 | 比赛中打开规则并关闭 | 明示计时继续，比赛进度与开赛次数不变，不展示本题答案 |
| G08 | 窄屏与长正文，初次打开说明，宿主列表样式重置 | 从正文开头开始，步骤编号与示例牌图可见，正文单独滚动，关闭与主操作可见，无横向溢出 |
| G09 | 偏好存储被禁用，关闭说明再切换同题型难度 | 当前访问仍记住已读，不阻断临时练习 |
