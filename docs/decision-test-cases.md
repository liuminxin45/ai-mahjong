# 舍牌与牌型价值版本测试用例

Node 24.19.0，pnpm 9.15.0。自动化产物在忽略的artifacts、coverage目录；发布前记录源提交、宿主提交、题库摘要与验证结果。

|范围|条件与操作|预期|自动化入口|
|---|---|---|---|
|计番|普通型、七对与普通型并存、四张作两对、根、清一色、碰碰胡、金钩钓、多项叠加|采用支持的最高番型解释；三番封顶；四张不重复加根|decision-score与decision单元测试|
|物理容量|第五张、固定碰杠、见尽、刚弃牌|非法题设拒绝；弃牌不回袋；公开吃牌不允许|decision单元测试、旧引擎oracle|
|精确模型|一次至六次摸打、不放回、提前成牌、失败路径、后续重新选舍牌|路径权重与分母一致；首次成牌吸收；全部精确并列接受|decision:verify|
|两套策略|期望基础分与快听的最优舍牌不同；相同收益的次序|分别执行各自后续策略后统计，不拼接概率；同收益都接受|独立物理路径枚举|
|全题库|复建332题、校验哈希、母牌形去重、四阶段覆盖|240常规、80迁移、12例题；全部非零有效比较；例题不计独立样本|bank:verify、decision:verify|
|讲解|可能成牌分支、完整分组、番型叠加|抽牌与舍牌合法；没有跳过提前成牌；独立计番一致；平均值包含失败路径|verify-decisions|
|入门|孤张题、对子与边嵌两面|没有四张同牌；孤张题确有孤张且推荐唯一；学习不因随机牌复杂而提前跳级|题库验证、单元测试|
|递进|十题中八题最优、少于五题最优、知识点未覆盖、手动选级|只推荐相邻阶段，调整后重积累；先覆盖本阶段知识点；深度题主动开启|decision单元测试|
|记录|重复提交、提示后答对、重复复习、本地1/3/7天|独立样本不膨胀；复习改善单列；备份导入重新判分|decision、storage浏览器|
|画像|超过100条历史、同题重复、少样本、不同难度与窗口、异常用时|全历史参与；按条件分层；Wilson区间；中位数正确；提示复习不充样本|单元测试、宿主test:mahjong|
|模型边界|非法引用、伪造正确率、新统计、越权读删、缓存、并发与超时|事实由程序产生；只接受允许证据；同访客同快照复用；55秒截止；90天保留|宿主test:mahjong|
|旧数据|旧题、原报告、测验草稿、新旧混合备份|原始内容保留；旧牌效不改成新收益判断；旧读删仍可用|storage浏览器、宿主旧测试|
|交互|重复牌只选一张、刷新、提示、帮助、菜单与弹窗、主题、主滚动|选择和作答续接；后台与帮助暂停有效用时；Escape焦点正确；状态不丢|decision-browser、decision-storage-browser|
|布局|1920/1280/768/390/360/320，Chromium/WebKit，深浅主题|无页面横向溢出；手机七列、320六列；牌目标至少44px；所有可见牌图加载|decision-browser|
|路由|旧课程、分析、画像、复习、测验与比赛链接|兼容回到首页或相应弹窗；退出的功能不重新出现|decision-routes-browser|

每个核心文件分支覆盖率门禁95%，画像服务分支门禁90%。独立枚举与失败样本校验始终保留，覆盖率不替代正确性。

真人难度标定与实体手机测试需要另行执行，不能用模拟结果替代。
