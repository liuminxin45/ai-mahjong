# 连续舍牌训练 · 8.0.0

## 产品边界

进入即看到真实手牌。每组五副不同母牌形，初档从认牌形开始；一副起手之后沿自己的选择继续一两次。先确认、看回应，再继续；后续抽牌不会抢在解释之前出现。

保留安静的短句、留白、白玉牌与可选的纯音乐，移去必须读完的角色剧情。音乐默认关闭，第一次主动开启只获取一首，使用内容摘要缓存；静音、后台、其他标签接管与离开工具会停止声音。

三档按已审核内容映射：完整组合与对子；向听、搭子、七对路线；有效余量、见尽与公开碰杠。定向练习使用实际题目档位。普通组尽量优先未做过的母牌形；见过的牌形可以重练，但不扩充独立样本。

目标是向听最小，其次有效余量最大。并列全部接受。这不是完整成都实战的期望净分、番数最大化或对手危险度模型。三次训练窗口结束明确换起手，不伪称流局；真实提前成牌与窗口结束分开。

## 数据与服务

浏览器仍使用原 IndexedDB，新增 practice 命名空间，保留 tables、story、旧题与报告。反馈、当前实体选择、提示和有效用时都能续接；提示刷新后也不会变成独立样本。旧故事没有以牌效为作答目标，不追溯纳入新训练正确率。

快照9包含版本、题号、种子、实体舍牌与继续次数。服务端重建手牌和每次判分，舍掉客户端附加的分数；按母牌形去重，后续、辅助、重复单列。旧版8及更早接口继续可用。报告7只保存合法观察、练习方向和证据身份，不接受模型自写人格、数学或动机。

全部新训练记录参与分层统计；上传前由玩家确认。沿用私有报告 RPC、签名访客、同快照复用、90天保留与本人读取删除。未新增 SQL 表或浏览器数据库权限。55秒服务截止、70秒浏览器等待；失败不动本地记录。
