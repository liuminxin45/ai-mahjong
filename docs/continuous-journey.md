# 未完的牌谱 · 陪她打完这一局

版本 `sit-with-me-1`，SDK 7.0.0。五章各打一局连续麻将，不再固定每章五题或总计二十五次选择。

## 故事与场景

开场在除夕：哥哥进门，妹妹把包塞到沙发底下，请他替自己打牌。母亲在右、姨妈在左、舅舅在对面，妹妹在旁边记牌。第一章先交代这些关系，再教一次摸打。

第二章留在桌边，穿插窗外鞭炮与半个橘子。第三章出现车票，收局后在门口告别，随后明确切到“今年·清明前一天”。第四、五章是哥哥循着妹妹留下的本子重摆的牌局；妹妹的文字标作“页边的字”，不会预知今天的舍牌。母亲、袋子、白菊和明天上山的安排承接时间变化，不用一句病逝通知替代故事。

无论谁和牌或真正流局，章末仍有完整的收束。最后补完空格、把本子放进袋子，再去吃饭。结尾没有自动画像、再玩邀请或胜负评价。

六个场景分别是进门、家中牌桌、窗边、现在的柜子、摊开的本子、收好的饭桌。八个人物姿态为妹妹三种、舅舅两种、母亲过去与现在、姨妈一种。原始 PNG、全部提示词与发布摘要分别在 `assets/journey/original`、`prompts.json`、`manifest.json`。使用内置 imagegen 生成，发布只做尺寸与 WebP 编码，保留透明通道。手机一套场景与人物合计 529,986 字节。

## 一副牌怎样继续

十五种经过筛选的开局，五章各三种。开始时绑定配置和牌墙种子；种子只洗这份既定牌墙。所有席位的手牌、四份有顺序的牌河、未摸牌墙共同恰好包含七十二张实体牌。每张以“牌种:副本号”标识。

玩家只打牌。四席轮流摸打，可接炮或自摸；自动和牌，无吃碰杠操作。NPC 按自己手牌与公开牌河比较向听和进张，不读取别人手牌或未来牌墙。多家同时可和时，按出牌者后方的轮转顺序取第一家，这是本工具的单局结束约定。它不声称还原完整四川血战结算。

一张打进自己的牌河，其他三席依次行动，再摸入一张。原有十三张实体和 DOM 标识保留，新牌单独显现。第一章初始各家均未听牌，任何第一张舍牌都能继续到至少第二次玩家出牌。开头与结尾自有牌形相同，公开牌不同，三个配对开局都实际改变了牌效最优选项。

异步计算用独立 Worker。回复要同时匹配局号和事件序号；提交带固定命令 ID，重复同一命令不会多打一次。先留下玩家命令，再计算后续；刷新按命令重放到可操作位置，不重复抽牌。菜单与后台暂停呈现和有效用时；动画中的事实即使已经算好，也不会突然补播。

## 回望的边界

新快照 8、回望 6。仅上传开局引用、种子与出牌命令；服务端重建每一步，浏览器的隐藏状态、正确率和文字结论都不作为证据。

当前解释只谈可公开验证的牌效：离听牌的距离、能缩短一步的未见牌数、不同公开条件下的对照。未见张数不冒充牌墙概率。牌效比较不是完整实战期望净分，也不因为追番而自动认定玩家贪心或犯错；未来输赢不反过来改写作答时的信息。

同局多次出牌相互关联；相同开局重复或更换牌墙种子不新增独立样本。首尾配对、辅助示例分别记录。重复观察只在同档至少五个不同开局，且同一事实出现至少三次时开放；准确率和 Wilson 区间按档计算。前三个开局版本不能支持对每个难度作稳定人群能力推断，五局通关也不等于完成可靠测评。

模型只能选择已核验的观察和人工自问，证据 ID 由服务端补齐并验证。请求前主动确认；现有签名访客、私有存档、90 天保留、55 秒服务截止和 70 秒客户端等待不变。旧快照、旧题和旧报告沿用原判题器，不追溯解释成新牌局；IndexedDB 的旧 `story` 字段不被覆盖。

## 运行与发布

资源首轮完整校验、解码后才允许推门。界面只显示短句和细进度，不显示 MB 或“准备声音”。五首配乐与六类音效仍由 GitHub 的固定资源提交提供；首次点击解锁浏览器播放，主题继承宿主。牌、场景和人物依内容摘要在 CacheStorage 中复用；代码更新不重复下载未改变的文件。无持久存储时，本次内存准备完成也可开始。

宿主先升级兼容服务与固定 SDK，暂从 `/legacy-story-app` 继续显示原故事；健康检查到快照 8 后再把前端切到新入口。资源地址带内容摘要，配置一年 immutable 缓存。恢复上一个固定 SDK 可回滚；浏览器的新旧记录均留下。

```sh
pnpm dev
pnpm test:coverage
pnpm exec tsx scripts/verify-journey.ts
pnpm test:oracle
pnpm bank:verify
pnpm story:verify
pnpm check:ui
pnpm build && pnpm build:package
# 另开预览，或设置 MAHJONG_PREVIEW_URL：
pnpm test:journey-browser
```

浏览器仿真、实体手机和真人试玩分别记载，见 [连续牌局验收](continuous-test-cases.md)。
