# 未完的牌谱：兄妹篇制作约定

这是原创虚构故事。现在是清明前一天，哥哥帮母亲清理餐边柜；过去是他刚工作那年、妹妹从大学放假回家的除夕。妹妹上一年冬天因病离世，仅作为作者时间线事实保存。玩家通过母亲准备去墓园的袋子理解缺席，没有病名、遗言或突然揭晓的说明卡。

前两章先让她活在小事里：护着对子，拿舅舅的橘子，抢着把赢牌算自己头上，把本子压到哥哥的手机上。第三章读到她后来独自练过的题，章末回到现在。第四章仍能在记忆里陪她坐一会儿；第五章由哥哥照她留下的题重摆，不能让她预测本次玩家的选择。

35张制作卡见 `sibling-production-cards.json`。每条路径25手；第十手是否拆对、第二十手重演结果分别决定两个菱形分支，四条路径读到同样的核心剧情。纸背最后一句“现在还给你”来自她生前写下的练习，不是遗言。最终行动是把本子放进自己的包，推回椅子，去吃饭。

## 牌里的意义

- 护住或拆开对子，改变她伸手拦牌又松开的动作；第十手还实际决定后面翻到哪种题。
- 第三手桌上四张七条真实存在；第七手共用的一张不能同时算进两种牌形。反应不能只按“对／错”换一句安慰。
- 追大有代价，也有值得的时候。她后来改过答案，不等于哥哥从来都正确。
- 首尾自有手牌相同，公开信息与推演条件不同。成对观察只说实际选择及条件差异，不把隐藏权重当作玩家已知知识。
- 对手局面有合法隐藏状态和精确证书，但新故事没有展示候选权重，因此只保留选择和结果，不纳入能力正确率。旧版本的公开条件记录仍按旧协议重判。

## 美术与声音

五幅原创插画使用 imagegen 生成，保存原始PNG、制作记录和内容摘要。暖象牙纸、略歪的铅笔线与轻淡水彩反复呈现椅子、橘皮、纸鸟、本子；对象放在边角，中央留给阅读。手机完整呈现下方插画，不把人物头像塞进对话框。不复用DEEMO角色、树、钢琴画面、旋律或界面。

第一章 Clear Waters，第二章 Heartwarming，均为作者标注的明亮或轻盈钢琴；之后使用 Evening Fall — Piano、Touching Story、Reaching Out。结尾回返开场旋律。音频固定从GitHub资产提交下载，不进入网站静态发布包。资源到齐后“翻开”手势解锁音乐；浏览器禁止无手势有声自动播放，不能把没有响起的音乐伪装成已播放。

加载只显示书名、短句与细线。所有音频、当前尺寸牌图和五幅背景全部校验并准备好，才可翻开。静音是读者自己的选择，不影响画像。

## 参考与取舍

- [Florence GDC分享](https://www.gdcvault.com/play/1025694/Letting-Go-A-Florence)与[创作者访谈](https://www.gamedeveloper.com/audio/designing-i-florence-i-to-convey-the-ineffable-feeling-of-being-in-love)：从普通互动认识人物，让操作承接关系变化，不复制其具体剧情或拼图。
- [DEEMO官方介绍](https://rayark.com/en/games/deemo/)：借鉴钢琴与安静留白承担叙事空间，原创美术和人物关系另行建立。
- [作曲者官方曲目数据](https://incompetech.com/music/royalty-free/pieces.json)：核对乐器与情绪标签；许可、处理方式逐曲保存在声音清单。原先的Earnest标为Dark/Somber，不用于轻松开场。

这些参考不能证明玩家一定感动。真人对妹妹的印象、揭晓是否自然、真实手机声音中断和整段听审，分别记录，不能用浏览器脚本代替。
