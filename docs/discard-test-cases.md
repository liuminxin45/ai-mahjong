# 舍牌学习版本测试用例

自动化结果与截图在忽略的 artifacts/、coverage/ 中；以下说明测试入口和判定边界。

| 范围 | 条件和操作 | 预期 | 命令 |
|---|---|---|---|
| 规则和算法 | 普通型、七对、四张作两对、暗手四张、碰杠容量、第五张、见尽与刚弃牌 | 不制造第五张等待；余量正确；全部并列接受 | pnpm test:coverage |
| 独立算法 | 10000个双花色随机样本，包含公开碰杠；与独立合法完整目标枚举对照 | 向听逐例一致；新题96道逐舍牌、逐摸牌余量另对照 | pnpm test:oracle；tests/training.test.ts |
| 新题库 | 重建96题；按花色互换、数字镜像和排列归一后去重；检查八课覆盖 | 每课12种结构，含1道例题；前七课14张全暗手，已成牌不强迫舍牌 | pnpm bank:verify |
| 练习编排 | 新用户、无错题、有到期错题、复杂旧错题、手动选课、最近10题7/8正确 | 每组5题，不把例题当独立样本；复杂碰杠题不提前插入；8/10后引入下一课 | tests/training.test.ts |
| 答题记录 | 错答后答对、提示后答对、重复题、重复提交 | 首次独立样本不膨胀；提示单列；本地日期1/3/7天复习 | tests/training.test.ts |
| 刷新和计时 | 选择重复牌中的一张、刷新、提交、刷新、打开规则、切后台 | 只选一个物理位置；答案与提示恢复；不重复记录；帮助和后台暂停有效用时 | training-browser.mjs；training-storage-browser.mjs |
| 旧记录 | 导入含何切、其他题型、比赛和多步的旧备份 | 只迁入目标和答案一致的何切；原始记录、测验草稿可原样导出 | tests/training.test.ts；training-storage-browser.mjs |
| 存储失败 | 禁用IndexedDB后练习与下载备份 | 明确提示临时练习，仍能提交和导出 | training-storage-browser.mjs |
| 画像证据 | 一道独立作答、仅提示作答、211条含重复历史、伪造题号和正确率 | 一道可生成初步小结，提示独立样本为零；全量重判再压缩；不相信客户端统计 | 宿主 npm run test:mahjong |
| 画像服务 | 缓存、并发、存档失败、模型幻觉、55秒超时、跨访客读删、90天过期 | 不重复付费；失败可重试；只接受学习动作；越权404；过期不可读 | 宿主 npm run test:mahjong |
| 比赛下线 | POST新开赛、原答卷逐题提交/恢复/过期/重复交卷 | 新开赛410；旧答卷仍受原24小时约束；不延长、不删除历史 | 宿主 mahjong-competition.test.mjs |
| 手牌编辑 | 点击添加、第五张、撤销、可选文字输入、碰杠与已见牌、刷新 | 操作有效；非法输入定位；推荐先展示，技术表格折叠 | analysis-browser.mjs |
| 交互与布局 | Chromium/WebKit，1920/1280/768/390/360/320，深浅主题，触屏模拟 | 不横向溢出；手机7列/320时6列；44px目标；弹窗Escape回焦点 | training-browser.mjs；analysis-browser.mjs |
| 站点集成 | 首页、深链接刷新、旧链接、导航切页 | 首页一篇最新文章与一个最新造物；不提前加载工具；旧链接不404；状态不丢失 | 宿主 test:home 与集成浏览器验证 |

核心算法和判分分支覆盖率门禁95%，画像和比赛兼容服务90%。覆盖率不替代独立算法对照。尚未执行真人难度标定和实体手机验证，不对这两项宣称通过。
