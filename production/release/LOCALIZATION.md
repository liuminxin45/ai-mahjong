# 本地化覆盖核对（Localization）— v0.1.0

> neo-mahjong · 成都麻将 AI 教学平台 · 2026-08-14

## 1. 现状概览

- i18n 实现：`src/i18n/translations.ts`，双 locale —— `zh`（第 381 行起）、`en`（第 742 行起）。
- 文案字段总数约 950 个（中英两树）。
- 语言切换：`src/store/languageStore.ts`，运行时可切换。
- 本轮新增音频设置分区已补齐中英双语字段（audioTitle / audioEnabled / audioSfxVolume /
  audioBgmVolume / audioVoiceVolume / audioReduceIntensity）。

## 2. 中文（zh）—— 主语言 ✅

- 全部界面、规则讲解、AI 教练、设置项均为中文优先。
- 状态：**完整，作为发布基准语言**。

## 3. 英文（en）—— 次语言 ⚠️ 有已知缺口

| 项 | 状态 | 说明 |
|----|------|------|
| 文案字段 | ✅ 覆盖 | translations.ts 含完整 en 树 |
| 界面文本 | ✅ | 设置、按钮、提示均有英文 |
| **牌面美术** | ❌ **缺口** | `tileView.ts:202` 读取 `languageStore.getLanguage()`，**仅 `zh` 渲染牌面图片**；英文模式退化为文本牌（如 `W1`）。美术表现与语言耦合，而非与"图形/文字牌"这一独立设置解耦 |
| 番型/规则术语 | ⚠️ | 成都麻将专有术语（血战、定缺、查大叫、刮风下雨）的英文表达未做术语表统一 |

## 4. 结论与建议

- **v0.1.0 以中文为主要交付语言发布**：英文模式可用但牌面为文本降级，规则正确性不受影响。
- **下一版本（0.2.0 候选）**：将"牌面图片/文字"从语言判定中解耦为独立的图形设置项，使英文模式也能渲染像素牌面；并为成都麻将术语建中英术语表。

## 5. 发布口径

对外说明中明确：**本版本推荐中文体验**；英文为可用但未做完整美术本地化的过渡状态。
